# Contributing

The contributing guide is
[`docs/contributing.md`](docs/contributing.md), also published on the
[documentation site](https://haochenpan.github.io/diaspora-service/latest/contributing/).
It covers the development setup, the pre-commit hooks, the unit and live
tests, how the dependencies are locked, how releases are made, the commit
and pull request conventions, and what merging to `main` does: a merge
that changes code deploys the service to production.

Ask questions and report bugs in the
[issue tracker](https://github.com/haochenpan/diaspora-service/issues).
Report a vulnerability privately, as the
[security policy](.github/SECURITY.md) says, and not in an issue or a pull
request.
